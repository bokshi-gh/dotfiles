# NvChad

## Post [setup.sh](./scripts/setup.sh)

### Nerd Font

Set **JetBrainsMono Nerd Font** as your terminal font.

### Install Plugins

After `lazy.nvim` finishes:

```vim
:MasonInstallAll
:TSInstallAll
```

### Remove Git

```bash
rm -rf ~/.config/nvim/.git
```
